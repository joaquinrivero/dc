# Color Select Block

A block that provides a color selector dropdown and displays the selected color in a 500x500 div.

## Usage

Add the following block structure to your page:

```html
<div class="color-select">
  <div>
    <div>Color Select</div>
  </div>
</div>
```

## Features

- Dropdown with 5 color options (Red, Blue, Green, Black, White)
- 500x500 preview area that displays the selected color
- Auto-initializes when block enters viewport
- Responsive design

## Technical

This block demonstrates:
- Dynamic DOM manipulation
- Event handling
- Milo block architecture
- Accessibility considerations for color selection
